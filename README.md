# math-app-v1

An adaptive math-learning game for kids, from kindergarten through 8th grade (and designed to extend past it). It runs on Amazon Fire tablets and in any web browser.

The goals:

- **Adaptive mastery.** Find out what each child already knows, then teach and reinforce the concepts they need next.
- **A complete progression.** Follow the K–8 math progression they'll meet in school, built as a prerequisite graph so we can add grade levels later.
- **Fun first.** Present it as a game the kids want to keep playing, with math as the core mechanic.
